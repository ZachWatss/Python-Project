# Snowman — Python Word Guessing Game

A console-based word guessing game developed in Python as part of my programming coursework.

The project was designed to demonstrate my ability to structure a Python application using functions, file handling, data structures, validation, and modular programming.

## Technical Features

* **Modular program structure** using separate functions for different areas of functionality.
* **File handling** for reading and writing persistent game data.
* **Data processing** using lists and string manipulation.
* **Randomisation** to select words dynamically during gameplay.
* **Input validation** to handle invalid user input and maintain expected program flow.
* **Exception handling** using `try`/`except` to handle missing data files.
* **Scoring system** based on configurable difficulty levels.
* **Persistent scoreboard** that stores player scores and timestamps.
* **Data management functionality** allowing new words to be added to the existing word data.
* **Date and time handling** using Python's `datetime` module.
